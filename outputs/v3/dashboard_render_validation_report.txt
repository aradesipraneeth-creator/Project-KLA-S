1. METRIC SHAPE MISMATCH & ROOT CAUSE FIX:
   - Root Cause: In previous dashboard code, `gt_array` was occasionally loaded
     or un-squeezed as 128×128 or mismatched with 256×256 predictions (`bicubic_pred`
     or `v3_pred`), triggering a `ValueError: operands could not be broadcast
     together with shapes (256,256) (128,128)`.
   - Resolution: Implemented centralized shape validation via `validate_image_shape()`
     and `validate_metric_pair()`.
   - Behavior:
     * Input NoisyLR strictly validated as (128, 128).
     * Ground Truth target strictly validated as (256, 256).
     * Metrics (PSNR, SSIM, LPIPS, MSE, MAE, Edge Error) strictly verify matching
       dimensions before execution. Any shape mismatch raises a clear error rather
       than crashing or silently cropping/resizing.

2. SOBEL EDGE-MAP IMPLEMENTATION:
   - Implemented deterministic 2D Sobel gradient operator `compute_sobel_edge_map()`.
   - Native resolution edge maps generated:
     * Input Edge Map: 128×128
     * Bicubic Edge Map: 256×256
     * AIR-Net v3 Edge Map: 256×256
     * Ground Truth Edge Map: 256×256
   - Edge Error (L1 MAE between 256×256 AIR-Net v3 Edge Map and 256×256 GT Edge Map)
     calculated only when GT exists.

3. ROUTER DISTRIBUTION & BIAS DIAGNOSTIC:
   - Automated router evaluation executed across 2,880 training samples and 320 canonical
     validation samples.
   - Outputs generated:
     * `outputs/v3/indexes/router_statistics.csv`
     * `outputs/v3/indexes/router_distribution.png`
   - Summary: The router assigns soft probabilities across the 5 categories based strictly
     on the 10 input characteristic features without ground-truth leakage.

4. MANUAL UPLOAD BEHAVIOR & METRIC INTEGRITY:
   - Supports PNG, JPG, JPEG, TIFF, BMP, and NPY manual uploads.
   - Enforces 128×128 input dimension validation.
   - When Ground Truth is not uploaded, the dashboard explicitly displays:
     "Ground Truth unavailable — quantitative fidelity metrics cannot be calculated for this image."
   - Fake or estimated metrics are NEVER shown.
